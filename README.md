# ABYSS RUN — 深海探査局

スマートフォンのブラウザで遊べる、オリジナルの縦画面・深海ランゲームです。

## 遊び方
- 画面を左右にスワイプ、または左右をタップして潜水艇を移動
- 真珠を集めて、装備ラボで強化
- 紫色の古代遺物は真珠5個分
- 岩や機雷に当たると酸素が減少
- ブーストで一時的に衝突を回避
- 記録と強化は端末の localStorage に保存されます

## 公開
GitHub Pages は GitHub Actions から自動デプロイする設定です。
Repository Settings → Pages → Build and deployment → Source を「GitHub Actions」にしてください。
