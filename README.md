# NEON TOKYO — オープンシティ

iPhoneのブラウザで遊べる、日本を舞台にしたオリジナルのオープンシティ運転ゲームです。GTAシリーズから着想を得た自由走行・車両購入・配達ミッションを、独自の街とゲームシステムで楽しめます。Rockstar GamesのGTA Vそのものではなく、独立したオリジナル作品です。

## 操作
- 画面上の方向ボタンで車を操作
- 「加速」を押してニトロを使用
- 黄色いマーカーに近づいて「仕事」を押すと配達ミッションを完了
- 報酬でガレージから車を購入・変更
- 街のマップでプレイヤーと仕事の位置を確認
- PCでは矢印キー / WASD、Shiftで加速

## 保存
所持金、購入済み車両、選択中の車、完了した仕事は端末の localStorage に保存されます。

## 公開
GitHub Pages は .github/workflows/deploy.yml から自動デプロイします。
